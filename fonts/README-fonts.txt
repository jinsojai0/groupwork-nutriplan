ฟอนต์หลักของระบบ NutriPlan: Sarabun (น้ำหนัก 400, 600, 700)
แหล่ง: Google Fonts https://fonts.google.com/specimen/Sarabun (src_12)
สัญญาอนุญาต: SIL Open Font License 1.1

ไม่ได้แนบไฟล์ฟอนต์ในโฟลเดอร์นี้ วิธีใช้งาน:
1) ในโปรเจกต์ React ติดตั้งแพ็กเกจ  npm install @fontsource/sarabun
   แล้ว import "@fontsource/sarabun/400.css", "600.css", "700.css" ใน main.jsx
   หรือ
2) ดาวน์โหลดจากหน้า Google Fonts ข้างต้น แล้วใช้ไฟล์ WOFF2 ตามน้ำหนักที่กำหนด
